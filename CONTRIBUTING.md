# Mitmachen

Danke für dein Interesse! Das Projekt ist inoffiziell und rein lesend.

- **Fehler melden:** Issue mit Home-Assistant-Version, Integrationsversion und Log-Auszug.
  **Nie** Zugangsdaten, Cookies, `sid`-Werte oder persönliche Portal-Inhalte posten.
- **Nachrichten/Klausuren:** Wer einen Account mit diesen Modulen hat, kann mit
  anonymisierten Struktur-Beispielen (HTML ohne Inhalte) helfen.
- **Code:** Branch von `main`, kleine PRs, Tests für Parser mit synthetischen Fixtures
  (`tests/fixtures`, keine echten Daten). Merge per Merge-Commit oder Rebase, nicht squash.
- **Lizenz:** MIT. Kein Code aus GPL-Projekten (z. B. Lanis Mobile) übernehmen.
